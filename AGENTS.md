# Maintainer instructions

This repository owns shared GitHub community defaults. Start with the
[repository README](README.md) and [community defaults guide](docs/community-defaults.md).
The public profile and research index live in [docxology/docxology](https://github.com/docxology/docxology).

- Keep the shared contribution guide, security policy, pull request template, issue
  forms, and sponsor configuration in their documented locations.
- Scope changes to the default affected. Keep project-specific requirements in the
  owning project. Preserve private reporting instructions when editing templates.
- Check Markdown links and parse changed YAML. There is no local application to
  build. For manuscript changes, use the [pinned render workflow](docs/manuscript/README.md).
- Review GitHub's form and funding settings from their documented sources. Verify
  display on an inheriting repository without submitting issues or reports.

Run `git diff --check` and the [offline link check](docs/community-defaults.md#editing-and-verification)
before handing off changes.
