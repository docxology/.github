# docxology/.github

This repository provides default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for repositories owned by [@docxology](https://github.com/docxology).

Open an issue or pull request in the project it concerns. Check that project's
own instructions first. GitHub uses these defaults for supported files when
the project does not provide its own. For security reports, follow the
affected project's policy or use the shared policy linked below.

| Need | Start here |
| --- | --- |
| Prepare a contribution | [Contribution guide](CONTRIBUTING.md), [pull request template](PULL_REQUEST_TEMPLATE.md) |
| Report a security issue privately | [Security policy](SECURITY.md) |
| Maintain issue forms, funding, or shared guidance | [Community defaults guide](docs/community-defaults.md) |
| Understand or reproduce the design audit | [Manuscript source and pinned render](docs/manuscript/README.md) |

The [documentation index](docs/README.md) also links to the maintenance
backlog. The [public research profile](https://github.com/docxology/docxology)
is maintained in a separate repository.

- [Issue forms and chooser configuration](.github/ISSUE_TEMPLATE/)
- [Sponsor button configuration](.github/FUNDING.yml)
