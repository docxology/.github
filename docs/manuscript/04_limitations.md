# Limitations

This review describes tracked source and GitHub's documented discovery behavior. It does not measure adoption, form completion rates, reporting volume, or response times. Private vulnerability reporting and sponsor-button visibility depend on GitHub and on settings for the affected repository. The security policy's seven-day acknowledgement target is a stated commitment [@docxologyCommunityFiles]. Evaluating whether it is met would require reporting records outside the scope of this review.

Maintainers can verify configuration and navigation offline from a checkout. Confirming behavior in GitHub requires inspection after the files reach the default branch. A repository inheriting the account files and a repository with local issue configuration are distinct cases to check.
